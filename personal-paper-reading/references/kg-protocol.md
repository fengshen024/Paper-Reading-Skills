# 知识图谱与少样本推理专项协议

仅在涉及 KG 链接预测、归纳关系预测、少样本关系推理及对应笔记时使用。

## 先说明“未见”的对象

逐项记录训练、验证和测试的对象是否重叠；论文名称中的 inductive／few-shot 不能代替实际协议。

| 对象 | 需要明确的事项 |
|---|---|
| 实体 | 测试实体是否训练时已出现；是否只对部分实体未见；有无实体 ID 嵌入 |
| 关系 | 测试关系是否未见；关系词表、关系表示或语义信息是否预先可用 |
| 图与背景边 | 是否独立图；训练是否访问测试实体邻域或全背景图；哪些边被保留 |
| 任务与样本 | support／query 如何划分；few-shot 限制约束什么；不同阶段是否共用样本 |
| 额外信息 | 文本、预训练模型、外部图、缓存原型或候选库在何阶段构建 |

“少样本新关系”“新实体”“完全未见图”是不同泛化维度。分别叙述，不能用“训练／测试三元组不重合”推出实体或关系完全隔离。

## 子图、掩码和泄漏

- 子图从哪张图抽取，方向与跳数如何处理，是否取邻域交集，节点标记如何定义。
- 目标边及其逆边在抽图、编码、候选库构建等哪些阶段被移除；只在最终评分时移除可能不够。
- 共享连接模式是精确图论最大公共子图，还是软掩码／近似重构？依据算法区分，不能由概念名称推断精确求解。
- 所谓相似关系来自文本、结构、嵌入、人工别名还是监督标签？相似性权重如何算，候选范围是什么？
- prior／原型由哪个阶段的数据构建，是否依赖当前关系、支持集或查询；编码器是否共享、冻结或单独预训练。

检索或利用完整背景图不必然违规，但如果含有按所声称协议本应隔离的测试信息，就限制该归纳结论。需要结合任务允许的信息可见性判断。

## 评测与负样本

核对 sampled negatives／全实体排名、候选集合大小、采样方式、类型约束、head／tail 评测、filtered／raw ranking、已知真实三元组过滤、ties 和平均方式。

负样本数会影响任务难度和分数可比性。单凭“用了 50 个负样本”不能判定比较不公平；应核对各方法协议是否一致，以及该设置能支持何种实际应用结论。负采样还可能产生假负例，观察是否处理。

注意 AUC／AP 与排名指标 MRR／Hits@K 关注不同对象；收益不一致时分别报告。对候选集、负采样、类型过滤不同的分数不做直接优劣排序。

## 将研究兴趣转为可证伪假设

条件扩散、Gumbel-Softmax、相似关系增强和信息论约束只有与实际瓶颈对应时才建议采用。

例如怀疑“收益来自关系特异信息”，可考虑无先验、随机／打乱关系先验、统一均值先验与关系条件先验的对照，并匹配额外容量和信息来源。这只是研究方案示例，需要按真实方法选取对照，不能声称任何具体论文已做过这些实验。

讨论 Gumbel-Softmax 时区分可微松弛、采样随机性、温度和估计偏差；讨论扩散时明确生成对象、条件来源、训练目标和推理成本。仅把已有模块替换成更复杂模块，不自动构成有效创新。
